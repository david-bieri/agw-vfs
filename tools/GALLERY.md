# Adding photos to the "Impressionen" gallery

The gallery on `jahrestagung-2026.html` is driven by `data/gallery.js`; images live in
`img/gallery/` and are generated by `tools/gallery_add.py`. No build step, no bundler.

## One-time setup
```bash
pip install pillow pillow-avif-plugin
```

## Procedure (per batch of new photos)

1. **Generate the image variants.** From the repo root:
   ```bash
   python tools/gallery_add.py p1473 /path/P1011473.JPG  p1480b /path/P1011480b.JPG
   ```
   `pXXXX` is any short unique stem (becomes the filename + manifest id). This writes
   `img/gallery/{id}-480/-960/-1440.avif` + `.webp` + `{id}.jpg` (fallback) for each,
   and prints a manifest snippet.

2. **Add to the manifest.** Paste each printed snippet into `data/gallery.js` →
   `AGW.GALLERY.shots[]`, then replace the `TODO` captions:
   - `cap.de` / `cap.en` — the visible caption (also the lightbox caption).
   - `alt.de` / `alt.en` — accessibility text (shown if the image fails to load).
   - `w` / `h` are filled in for you (the original pixel size — fixes the grid aspect box).
   Reorder entries to reorder the gallery; the first entry shows first.

3. **Bump the service-worker cache.** `data/gallery.js` is precached, so edit
   `service-worker.js` → `const CACHE = 'agw-2026-vN-…'` to the next version.
   (The image files themselves are *not* precached — the SW caches them on demand — so
   they don't require a bump on their own; the manifest edit is what triggers it.)

4. **Commit + deploy.**
   ```bash
   git add data/gallery.js service-worker.js img/gallery
   git commit -m "content: add gallery photos (…); SW vN"
   git push
   ```
   Then unregister the service worker once (DevTools → Application → Service Workers)
   and hard-reload to see the new photos.

## Rules of thumb
- Keep widths at `[480, 960, 1440]` so new photos match the existing set.
- Never add image files to the SW `PRECACHE` list — they are runtime-cached on demand.
- Captions can be revised any time by editing `data/gallery.js` (one line each) + a cache bump.
