# Members' Publications — Review Sheet

This is a **review draft** for the new *Members' Publications* page. Nothing has
been committed to the live site yet. Please mark up anything you'd like changed:
rename or merge themes, re-tag publications, correct metadata, add/remove items,
or reassign a publication to a different member.

There are two things to review:

1. **Thematic categories** — the headings the page groups publications under.
2. **Seeded publications** — the 17 starter entries (a representative set so the
   page isn't empty; meant to be replaced/extended over time).

---

These were derived from the `focus_de` / `focus_en` keywords already on the

under each relevant heading. Empty themes are hidden automatically. The `Order`

**Open questions for you:**

- Are 12 categories the right granularity, or would you prefer fewer, broader
  buckets (e.g. merge `evolutionary` into `institutional`/`general`)?
- Is `general` ("History of Economics") a useful catch-all, or should every
  publication be forced into a more specific theme?
- Any category missing? (e.g. *German Historical School / Historische Schule*,
  *Marxian / Marxistische Ökonomik*, *Cameralism / Kameralismus*, *Public
  Finance / Finanzwissenschaft*.) These are easy to add.
- Wording of any label — these are the exact strings that appear on the page.

## How to give feedback

You can either:

- **Reply in this chat** with changes in plain language (e.g. "merge `smith`
  into `general`", "Kurz 2016 should be tagged `general` and `classical`",
  "add a *Historische Schule* category", "remove entry #2"), and I'll apply them; or
- **Edit this file directly** and tell me, and I'll sync the data file to match.

Once you approve, I'll finalise `agw_member_pubs.js`, run a last check, and
commit + deploy (including the two planning docs, as you confirmed).
